# Окказио 🔎

Крошечный инструмент, который находит в русском тексте **слова, которых нет в словаре**, то есть кандидатов в окказионализмы (авторские слова). Если слово похоже на «склейку» двух известных, он покажет, из чего оно, возможно, собрано.

Один файл, около 60 строк кода.

## Установка

```bash
git clone https://github.com/sherzodboboqulov0307-upg/okkazio.git
cd okkazio
pip install -r requirements.txt
```

## Запуск

```bash
python okkazio.py sample.txt
```

Пример вывода:

```
• кофечай  (×1)  ← кофе + чай
    …несли в руках кофечай и маленькие пустотелефоны…
```

## Как это работает

1. Текст разбивается на слова.
2. Имена собственные (слова с заглавной не в начале предложения) пропускаются.
3. Слово, которого нет в словаре [pymorphy3](https://github.com/no-plagiarism/pymorphy3), становится кандидатом.
4. Программа пробует разбить кандидата на две знакомые части.

## Ограничения

Это подсказчик, а не судья: он находит и настоящие окказионализмы, и опечатки, и редкие слова. Последнее слово остаётся за исследователем.
